🚀 Setup Instructions

1. Copy Environment File

copy .env.example .env

2. Generate App Key

php artisan key:generate

3. Create MySQL Database

Buat database invoices di MySQL/phpMyAdmin, atau jalankan:

CREATE DATABASE invoices CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

4. Run Migrations

php artisan migrate

5. Seed Database

php artisan db:seed

6. Access Application

http://localhost/invoices

Workflow Steps:

  • Create PO - Purchasing membuat PO dengan status Draft
  • Submit - PO dikirim untuk approval (status: Pending)
  • Approve/Reject - Manager mereview dan mengambil keputusan
  • Print - PO yang approved bisa dicetak ke PDF

✨ Features Implemented

Dynamic Reusable Components

  • Form Component - Supports text, textarea, select, checkbox, file, money, date fields
  • DataTable Component - Server-side processing dengan filter dinamis
  • CRUD Templates - Index, Form, Show layouts minimal code
  • Action Buttons - View, Edit, Delete dengan konfirmasi SweetAlert

SweetAlert Integration

  • Toast notifications (success, error, warning, info)
  • Delete confirmation dialogs
  • Form validation alerts

Purchase Order Module

  • Dynamic product rows dengan AJAX search
  • Real-time calculation (qty × price = subtotal)
  • Auto-generated PO number (PO/YYYYMM/XXX)
  • Timeline activity di detail view
  • Print-ready view dengan signature boxes
